Layout

Operations Rules

  • Series number — set seriesNumber per card; formats as #NNN with zero-padding
  • Difficulty — set showDifficulty: false to hide the tag entirely (e.g. for "teaser" covers)
  • Easy / Medium / Hard — currently 2 / 4 / 6 removed pieces; extend DIFFICULTY_DOTS as needed
  • Colors — edit PIECE_COLORS at top of script to match any future palette change
  • Font — Inter via Google Fonts; swap to a local font by changing the <link> tag
